# LeadMate V2.4.7

## 핵심 변경
일반 사용자용 요금제 화면에서 개발/진단용 UI를 정리하고,
관리자 기능은 동일한 `/billing` 페이지 하단에 관리자 계정에서만 표시되도록 통합했습니다.

### 일반 사용자에게 보이는 항목
- 현재 구독 상태
- 다음 결제 예정일
- 고객 사용량
- 카드 등록/변경
- 결제내역
- 개인형 / 팀·사업장형 요금제
- 자동결제 해지
- 지인추천 혜택

### 일반 사용자에게 숨긴 항목
- 결제 환경 진단
- 비즈니스 접근 진단
- Toss SDK 단계 진단
- 개발용 테스트 결제 버튼
- 관리자 전체 구독 통계
- 무료/할인 특권 제어

### 관리자 계정에서만 추가 표시
`app_admins`에 등록된 계정으로 로그인했을 때 `/billing` 맨 아래에:
- 전체 사업장 수
- 구독 중 / 체험 중 / 미결제 통계
- 사업장 선택
- 무료 이용 부여
- 할인 부여
- 특권 해제
- 구독 현황 요약

이 표시됩니다.

관리자 여부는 UUID를 프론트 코드에 하드코딩하지 않고
Supabase `app_admins` 테이블을 서버에서 확인합니다.
