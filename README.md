# LeadMate V2.6

## 수정 내용
사이드 메뉴가 통합 이전 상태로 계속 보이던 문제를 수정했습니다.

### 일반 사용자 사이드 메뉴
- 홈
- 고객
- 통계
- 구독
- 설정

### 관리자 계정 사이드 메뉴
- 홈
- 고객
- 통계
- 구독
- 설정
- 관리자

`관리자`는 Supabase `app_admins`에 등록된 로그인 계정에서만 표시됩니다.

기존의 `요금제 / 결제내역 / 지인추천` 개별 사이드 메뉴는 제거했습니다.
각 기능은 모두 `/billing`의 `구독` 화면에 통합되어 있습니다.

## 원인
이전 AppShell 안에 새 `navItems`와 과거 `nav` 배열이 동시에 남아 있었고,
실제 화면은 과거 `nav` 배열을 렌더링하고 있었습니다.
