# LeadMate V2.4.8

## 화면 구조 개편

### 사이드 메뉴
일반 사용자:
- 홈
- 고객
- 통계
- 구독
- 설정

관리자 계정:
- 홈
- 고객
- 통계
- 구독
- 설정
- 관리자

`관리자` 메뉴는 `app_admins`에 등록된 계정으로 로그인했을 때만 표시됩니다.

### 통합
기존의:
- 요금제
- 결제내역
- 지인추천

세 메뉴를 하나의 `구독` 페이지(`/billing`)로 통합했습니다.

### 구독 페이지 구성
- 현재 구독 상태
- 고객 사용량
- 카드 등록/변경
- 요금제
- 지인추천 ID/추천 현황/크레딧
- 최근 결제내역
- 자동결제 해지

### 관리자
관리자 기능은 일반 구독 화면에서 제거했습니다.
관리자 계정에서만 사이드 메뉴의 `관리자`가 보이며,
`/admin/subscriptions`에서 전체 사업장 구독을 별도로 관리합니다.
